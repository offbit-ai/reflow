# Tutorial 02 — WebGPU SDF in the browser

Runnable code for [Real-world Reflow 02: WebGPU SDF in the
browser](../../../../docs/tutorials/real-world/02-sdf-canvas.md).

## Run

```sh
npx serve .
```

Open the URL it prints. Move your mouse to orbit the camera.

Requires a WebGPU-capable browser (Chrome 113+, Edge, or Safari
Technology Preview at the time of writing).
