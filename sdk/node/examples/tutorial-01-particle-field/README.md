# Tutorial 01 — Reactive particle field

Runnable code for [Real-world Reflow 01: Reactive particle field in
the browser](../../../../docs/tutorials/real-world/01-particle-field.md).

## Run

```sh
npx serve .
```

Open the URL it prints. Move your mouse.

The HTML pulls `@offbit-ai/reflow` from `esm.sh`, so no local install
is needed.
