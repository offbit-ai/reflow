# `@offbit-ai/reflow-wasm`

Browser-WASM build of the Reflow runtime.

The npm package is generated by `wasm-pack` from
[`crates/reflow_rt_wasm`](../../crates/reflow_rt_wasm/) — there is no
hand-written JS or TS in this directory, only the published artifact
under `pkg/` (gitignored; built by [the publish-wasm CI](../../.github/workflows/publish-wasm.yml)).

## Building locally

```sh
# from the repo root
wasm-pack build crates/reflow_rt_wasm \
  --target web \
  --release \
  --scope offbit-ai \
  --out-dir ../../sdk/wasm/pkg
```

The output is at [`pkg/`](pkg/) and is itself a publishable npm
package (`pkg/package.json`).

## Publishing

Tag a release as `wasm-vX.Y.Z` on `main`. The
[`publish-wasm`](../../.github/workflows/publish-wasm.yml) workflow
builds the bundle, rewrites the package name to
`@offbit-ai/reflow-wasm`, and runs `npm publish --access public`.

## Quickstart

```js
import init, { Graph, GraphNetwork, version } from "@offbit-ai/reflow-wasm";

await init();
console.log(version()); // "0.2.0"

const g = new Graph("demo");
g.add_node("a", "tpl_doubler");
g.add_node("b", "tpl_collector");
g.add_connection("a", "out", "b", "in");

const net = GraphNetwork.from_graph(g);
net.register_actor_js("tpl_doubler", { /* JS class with run(ctx) */ });
net.start();
```

For DOM input wiring (keyboard, mouse, touch, resize → input actors)
see `bindInputEvents` in the bundle's TypeScript declarations.
